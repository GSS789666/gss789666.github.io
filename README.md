# Shengshuo Gong · Personal portfolio

Chinese, English and Russian portfolio covering robotics research, education and professional experience.

Website: https://gss789666.github.io/

`site.zip` contains only the reviewed static website: HTML, CSS, JavaScript and public images. The GitHub Pages workflow unpacks and publishes that archive. The local editor, private profile, certificates and application records are not included.

To update the website, build and check the local project, replace `site.zip` on `main`, and wait for the Pages workflow to complete. The archive must contain `index.html` at its root.

This is the initial deployment-test version. Search indexing remains disabled until the public content is finalized. This setting is not an access restriction.
